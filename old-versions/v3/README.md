## 📘 Version History — My Development Story

### 🌱 **v1.x — The Beginning**
- My first attempt at building a real portfolio  
- Simple HTML + CSS  
- No fancy features, just passion  
- Pure excitement of starting something new  
- I didn’t know much, but I loved creating  

This version reminds me of the moment I stepped into the world of web development.

---

### 🛠️ **v2.x — Learning to Shape Ideas**
- A stronger structure  
- Cleaner layout  
- More refined UI  
- Experiments with responsive elements  
- Started caring about user experience  

This was the phase where I tried, failed, fixed, learned, and improved.  
It taught me that design is not just looks — it’s how users feel when they visit.

---

### 🚀 **v3.0 — A Major Evolution**
- My first truly polished and themed portfolio  
- Dark space UI  
- Better animations, sectioning, and readability  
- Confidence growing in both design and code  
- A version I was proud to show the world  

This version felt like a real leap — a new identity for my portfolio.

---

### 🌌 **v3.5 — The Current Live Version**
> **This is where I stand today.**

- Transparent, minimal footer  
- "Resources" and "Connect" sections  
- A clean “More…” popout for deeper social links  
- Accessibility improvements  
- More thoughtful styling and layout decisions  
- A better reflection of who I am now  

v3.5 is not just an update —  
it’s a symbol of how I think, create, and build today.
